About the first proposition: <blockquote><header class="quote-author">Citation : malife</header>see what are the actual values being set for the involved registers</blockquote><br>
This is difficult since for most peripheral, Theses register's values are not computed at the matlab workspace level but directly in the C code generated. <br>
<br>
Btw, isn’t it possible to avoid the "buggy special condition" by using configuration parameters itself?<br>
<br>
<br>
<br>
For the second point, You just have to add "-merrata=exch" at the end of :  menu Simlation ==&gt; Configuration Parameters ==&gt; Real Time Workshop -&gt; dsPIC Options -&gt; Optimisation Parameters : OPTIM_GCCLine ==&gt; -mcpu=33fJ256MC710 -O3 -fschedule-insns -fschedule-insns2  -merrata=exch<br>
<br>
<br>
<br>
The, You should remove the directory generated by Real Time Workshop so as to have all the matlab library compiled with this new parameter.<br>
<br>
<br>
<br>
Let me know if you can't find a workaround for the first problem mentioned...</div>

<br>
