<h3>Re: c code and mplab</h3>
<div class="forum-post-body">ropeekollee,<br>
<br>
<br>
<br>
C code generated by simulink can be imported into any microcontrollers or DSP that have a C compiler which can compile "standard C".<br>
<br>
<br>
<br>
Anyway, most microcontrollers (and dsPIC) have an PWM peripheral. In other word, the PWM signal is generated by the internal electronics. You just need to set-up the peripheral. The block Output Capture (OC) or PWM motor generate the C code that set up and configure the peripheral for dsPIC for you if you use a dsPIC.</div>
</article>
