<h3>Re: Problem of configuring a dspic with Simulink Blockset</h3>
<div class="forum-post-body">Alpert,<br>
<br>
<br>
<br>
This look like a problem with few compilers version as the FICD register were renamed as ICD.<br>
<br>
Some blockset version used FICD or ICD as register to comply with the latest compiler.<br>
<br>
<br>
<br>
please download the latest C30 (v3.31) compiler version and the latest blockset (v3.7c)<br>
<br>
Everything should works fine now.<br>
<br>
<br>
<br>
Lubin</div>
