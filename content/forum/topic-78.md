<h3>Re: view the PWM signals in simulink platform</h3>
<div class="forum-post-body">Hi Nanshi,<br>
<br>
<br>
<br>
The aim of the dsPIC blockset is not to simulate the behavior of the dsPIC or PIC24 peripheral. Its aim is to automatically generate the C code to configure these peripheral, and to integrate this code into the C code generated by Simulink and the Real Time Workshop Embedded Coder toolbox.<br>
<br>
<br>
<br>
If you need to simulate the behavior of the dsPIC peripheral, you can do it using the standard simulink block library. However, you will probably have to reduce the time step of the model. The PWM peripheral is a good example: The resolution of the dsPIC peripheral Pulse Width is independent from the model time step! A model running on the dsPIC at 1 KHz (model time step = 1ms) could have a physical PWM resolution higher than 1ms!<br>
<br>
<br>
<br>
If you want to simulate and to generate C using the same model, the block <a href="http://www.mathworks.com/access/helpdesk/help/toolbox/simulink/slref/environmentcontroller.html">Environment Controller</a> from the standard simulink library could be helpful.</div>
