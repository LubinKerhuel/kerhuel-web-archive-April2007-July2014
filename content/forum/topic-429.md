<div class="forum-post-body">Blockset version 3.6 auto-generates a project folder for Microchip MPLAB X. Thanks Lubin--NICE!<br>
<br>
I am a beginner with MPLAB X, but these steps worked for me:<br>
<br>
<br>
<br>
Build the Simulink project and open MPLAB X.<br>
<br>
Click the Open Project icon (or File &gt; Open Project… or Ctrl + Shift + O).<br>
<br>
Navigate to the Matlab working directory and select the project folder: model_name_dspic.<br>
<br>
MPLAB X opens the auto-generated project. Source files are visible.<br>
<br>
Click the Debug Project icon (or Debug Menu &gt; Debug Project or Ctrl + F5).<br>
<br>
MPLAB X asks for the tool to use. Select your programming device. Mine is PIC32 starter kit.<br>
<br>
MPLAB X automatically builds, connects to hardware, programs, and runs the program.<br>
<br>
After making changes to the Simulink model and rebuilding, click the “Finish Debugger Session” icon.<br>
<br>
And then click the Debug Project icon again to reprogram.<br>
<br>
Or to program without the debugger click the icon to “Make and Program Device.”<br>
<br>
<br>
