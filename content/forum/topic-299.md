<br>
It is possible to have two matlab version installed on the same computer.<br>
<br>
<br>
<br>
However, with Windows 7 64 bits, too old matlab version do non install properly (below 2007a as far as I remember)<br>
<br>
Anyway, you can install 64 and 32 bits matlab. You’ll just need to re-create matlab starting shortcut as they takes same place and names for 64 or 32 bits of same matlab version (i.e. 2010a) .<br>
<br>
<br>
<br>
Solution for older matlab is to use a dual boot (what I get now : my older system (XP32) in // with the new one (7-64) which I install on a brand new hard drive) or more practically : virtualization (install a windows XP 32 in a <a href="http://www.vmware.com/fr/products/player/">VMware</a> virtual computer)<br>
<br>
<br>
<br>
Lubin</div>
